# KESA Mobile — Android и iOS

Мобильный проект на Expo / React Native, который подключается к существующему серверу:
`https://kesa-messenger.onrender.com`

## Что реализовано в этой стартовой версии
- Вход и регистрация через `/api/auth/login` и `/api/auth/register`
- Безопасное локальное хранение токена через `expo-secure-store`
- Восстановление входа при повторном запуске
- Список чатов и просмотр сообщений
- Отправка текстовых сообщений
- Поиск пользователей по `/api/users/search?q=...`
- Создание групп и создание личного диалога
- Тёмно-фиолетовый мобильный интерфейс
- Вкладки чатов, друзей, групп, звонков и профиля

## Честно о незавершённых возможностях
Текущий серверный API и маршруты звонков/загрузки файлов нужно сверить с фактическим `server/server.js`. Поэтому реальный WebRTC-аудио/видеозвонок, запись/отправка голосовых сообщений, добавление друзей как отдельная сущность, аватары и фон профиля ещё не подключены в этой стартовой сборке. Вкладка звонков показывает пояснение вместо фиктивного звонка. Также endpoint поиска ожидается как `/api/users/search?q=...`; если сервер использует другой формат, адаптируй путь.

## Запуск на Windows
1. Установи Node.js LTS с https://nodejs.org/
2. Распакуй архив.
3. Открой CMD в папке `KESA-Mobile`.
4. Выполни:

```bat
npm install
npx expo start
```

Установи Expo Go на Android/iPhone и отсканируй QR-код для теста. Для финальной установки APK используй EAS Build.

## Создать APK для Android
1. Создай аккаунт на https://expo.dev/
2. Установи EAS CLI:
```bat
npm install -g eas-cli
eas login
```
3. Создай проект EAS:
```bat
eas build:configure
```
4. В `app.json` замени `REPLACE_WITH_EAS_PROJECT_ID` на project ID, который выдаст EAS (либо повторно сгенерируй конфигурацию командой выше).
5. Запусти сборку APK:
```bat
eas build --platform android --profile preview
```
6. Когда сборка закончится, открой ссылку от EAS и скачай APK на Android.

## iPhone
APK на iPhone не устанавливается. Для iPhone нужна отдельная iOS-сборка через EAS:
```bat
eas build --platform ios --profile production
```
Для установки на реальное устройство и публикации могут потребоваться Apple Developer account и соответствующая подпись. Для быстрого теста можно использовать Expo Go.

## Важно
Перед реальным релизом нужно проверить все серверные маршруты, политику токенов, хранение сообщений/медиа и настроить звонки WebRTC. Не публикуй `.env`, JWT-секреты или пароли.
