KESA — Windows-клиент и сервер
================================

ВАЖНО: это полный исходный проект, но Windows EXE ещё нужно собрать на Windows-компьютере. Онлайн-чат между разными компьютерами требует размещённого в интернете сервера. В этой папке есть сервер и пример конфигурации Render.

СБОРКА WINDOWS EXE
1. Установи Node.js LTS с https://nodejs.org/
2. Распакуй папку KESA.
3. Открой CMD в папке KESA.
4. Выполни:
   npm install
   npm run build:win
5. Установщик появится в папке release.

ЗАПУСК СЕРВЕРА ЛОКАЛЬНО ДЛЯ ПРОВЕРКИ
1. Открой CMD в папке KESA\\server.
2. Установи Node.js LTS, затем выполни:
   npm install
   set JWT_SECRET=replace-this-with-a-long-random-secret-123456789
   npm start
3. В клиенте оставь client\\server-config.js с http://localhost:3210.
4. Собранный клиент подключится только к серверу на этом компьютере.

ОНЛАЙН ДЛЯ РАЗНЫХ КОМПЬЮТЕРОВ
1. Создай репозиторий GitHub и загрузи папку server.
2. На Render создай Web Service из этого репозитория, Dockerfile укажи server/Dockerfile.
3. Добавь переменную JWT_SECRET (случайная строка минимум 32 символа), а для постоянного хранения SQLite и файлов нужен постоянный диск, смонтированный в /var/data. Пример render.yaml дан как ориентир; проверь настройки диска в Render.
4. После публикации скопируй публичный HTTPS URL сервера в client/server-config.js вместо http://localhost:3210.
5. Пересобери EXE: npm run build:win.

ВОЗМОЖНОСТИ
- Регистрация и вход с хешированием пароля.
- Личные сообщения и групповые чаты.
- Отправка файлов до 25 МБ.
- Голосовые сообщения через микрофон.
- Стеклянный тёмный интерфейс с анимациями.

ОГРАНИЧЕНИЯ ПЕРВОЙ ВЕРСИИ
- Нет сквозного шифрования, звонков в реальном времени, восстановления пароля и push-уведомлений.
- Голосовые сообщения требуют разрешения на микрофон.
- Это стартовая версия: перед публичным запуском настрой HTTPS, лимиты, резервные копии, CORS и модерацию.
- Для одновременного доступа с разных устройств сервер должен быть доступен из интернета. Без хостинга онлайн-мессенджер не заработает.
